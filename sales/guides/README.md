## How to add a guide

1. Name it `<topic>-<lang>-<YYYY-MM-DD>.md` (and the same base name for a matching `.pdf`).
2. For Hebrew, wrap the body in `<div dir="rtl">` and include an anchor-linked table of contents.
3. Add a row to the table above, newest first. When a guide is replaced, move the old one to `archive/` and mark it superseded here.
4. Update **Latest materials** in the [main menu](../../README.md) and the [CHANGELOG](../../CHANGELOG.md).
5. Before adding a PDF, check its screenshots against the [privacy checklist](../../CONTRIBUTING.md#privacy-checklist).
