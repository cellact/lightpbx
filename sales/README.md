## How to add a file

1. Long-form guides go in [`guides/`](guides/README.md); other sales material goes directly in this folder or in a new, clearly named subfolder (e.g. `decks/`).
2. Name it in kebab-case with a language and date/version suffix, e.g. `pricing-overview-he-2026-12-01.md`.
3. Add a row to the table above (and to the subfolder index if you used one).
4. Add it to **Latest materials** in the [main menu](../README.md) and to the [CHANGELOG](../CHANGELOG.md).
5. Check the [privacy checklist](../CONTRIBUTING.md#privacy-checklist) — no discount codes, customer names or real phone numbers.
