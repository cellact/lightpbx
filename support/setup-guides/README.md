1. Copy [`docs/_template.md`](../../docs/_template.md) to this folder as `<task>-<lang>.md`, e.g. `invite-team-member-en.md`.
2. Use numbered steps and describe screenshots instead of showing real account data.
3. Replace the matching "To be filled" row above with a link, and add it to **Latest materials** in the [main menu](../../README.md).
