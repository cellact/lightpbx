## How to add a file

1. Living documents (`faq.md`, `troubleshooting.md`) are edited in place; record notable changes in the [CHANGELOG](../CHANGELOG.md).
2. New task guides go in [`setup-guides/`](setup-guides/README.md), named `<task>-<lang>.md`, e.g. `invite-team-member-en.md`.
3. Add a row to the relevant contents table and to **Latest materials** in the [main menu](../README.md).
4. Never include customer names, real phone numbers, invitation links or QR codes — see the [privacy checklist](../CONTRIBUTING.md#privacy-checklist).
