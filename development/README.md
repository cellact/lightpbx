## How to add a file

1. Name it in kebab-case, e.g. `call-flow-ivr.md`; add a version suffix for versioned specs (`-v1.0`).
2. Diagrams go in [`assets/`](../assets/README.md) and are linked with relative paths.
3. Add a row to the table above and to **Latest materials** in the [main menu](../README.md).
4. Run the [privacy checklist](../CONTRIBUTING.md#privacy-checklist).
